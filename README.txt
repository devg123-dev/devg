NILA LOVE WEBSITE — QUICK START

1. Open index.html in a browser to preview the website.
2. Add photos:
   - Put your images in the photos folder.
   - In index.html, replace each placeholder <div class="placeholder">...</div>
     with: <img src="photos/memory1.jpg" alt="Our memory">
   - Repeat for memory2.jpg through memory6.jpg. Keep the caption <p> below each image.
3. Add music:
   - Put an MP3 you are allowed to use in the music folder.
   - Name it exactly: our-song.mp3
   - The music button starts playback after the visitor taps it (browsers block autoplay).
4. Personalise the letter and captions by editing the text in index.html.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in or create an account at https://github.com/
2. Create a new public repository, for example: nila-love-website
3. Upload index.html and the photos/ and music/ folders (with your files).
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. Wait a minute or two. GitHub will show your public website URL in Settings → Pages.
8. Open that URL on your phone to test it, then share it with Nila.

NOTES
- Do not upload private or intimate photos unless both of you are comfortable with them being public.
- GitHub Pages sites in public repositories are publicly accessible to anyone with the link (and potentially discoverable).
- Use only music you own or have permission to share. Music is not autoplayed; Nila taps the music button.
- The page uses Google Fonts when internet access is available; it has fallback fonts too.
